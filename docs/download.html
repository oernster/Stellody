Once it is installed

Point it at your music.

Show it your music folder

You do this once. Press the folder button at the top left, point Stellody at wherever your music lives and it reads the lot. It remembers, so you never have to do it again.

Check your music is a format it reads

FLAC, MP3, Ogg, WAV and AIFF are all read. M4A and WMA are not, so if your music is in one of those Stellody will not find it yet. Worth checking before you download. The remaining formats are being worked on.

Adding music later is quick

Bought a new album? Press Rescan. Stellody only looks at what has actually changed, so it takes a moment rather than starting again from scratch.

It tells you about new versions

Stellody mentions it when a newer version comes out; it says nothing at all when there is not one. It sends nothing about you or your music when it checks, not even which version you have.

For developers only

Building it yourself

You do not need any of this to use Stellody: the download above is all most people want. This is for anyone who would rather build it themselves. It is Python 3.13 with PySide6. 

python -m pip install -r requirements-dev.txt
python main.py

The test suite gates at 100% branch coverage over the layers reachable with no filesystem, no clock and no audio device. It also runs black, flake8 and ruff as assertions, so a formatting or linting regression is a test failure: 

python -m pytest

The Windows build is two scripts. The first compiles the application with Nuitka using every core the machine has; the second zips that as a payload and compiles the setup program around it: 

python buildexe.py
python buildinstaller.py
