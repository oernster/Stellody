Why / Technical
For anyone who wants the detail

Under the bonnet.

You do not need any of this to use Stellody. The claims on the Why page are easy to make and hard to check, so this is the working behind them. The code is public.

Every guarantee is a test

The rules on the Why page are enforced by tests that stop the checks passing. Each test was itself checked by breaking the rule and watching it fail, because a guard nobody has seen fail is not yet a guard.

A track is a slice of a file

In the collection Stellody was built against, many albums come from a cue sheet, most of them a single file holding the whole album. That is a main path, so it is captured once in the core idea rather than special-cased throughout.

Search has no index

A full text index was the first plan; measurement refused it. With the text prepared once at load, reading all of it on every keystroke takes about a millisecond and a third, a small fraction of the gap between keystrokes. An index would also have held the wrong text.

Folders group, tags name

Grouping albums by their tags was tried on a real collection and split one Mozart folder into five albums. A folder boundary is what a ripper actually recorded, so that is what is trusted.

Measured rather than assumed

Drawing the waveform once took over three seconds for a long track; the same arithmetic done another way takes under one, with an identical picture. That is the rule here: time it, then keep the quicker way only where the answer is exactly the same.

Only what it uses is shipped

Each build carries its pictures at the most pixels a screen draws them and leaves out the Qt plugins and numpy parts nothing reaches. Measured on Windows, that took the setup program from 246.5 MB to 106.5 MB.

What a file does not say is not invented

A FLAC states its bit depth; an MP3 states none. Where a file says nothing, Stellody records that rather than a likely number, because an invented figure cannot later be told from a real one. That is what lets it refuse to call a lossy track bit perfect.

The rules stay clean

The part of Stellody that decides what an album is, which tracks belong to it and what it is called never touches your disk, the internet or even the clock.

It works from what it is handed alone, so it can be tested completely; every one of those decisions is tested each time the checks run.
